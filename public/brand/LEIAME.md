# Identidade visual UaiCasa

**Conceito:** casa mineira com telhado de telha, os ciprestes e a serra de São João del-Rei, e a onda da piscina.

| Cor | Hex | Uso |
|---|---|---|
| Verde Serra | `#2f5d50` | fundo do símbolo, botões de hospedagem |
| Verde Serra escuro | `#1f4037` | "Uai", textos, fundos escuros |
| Terracota | `#b4532a` | telhado, "Casa", botões de eventos |
| Terracota clara | `#e08a5f` | "Casa" sobre fundo escuro |
| Creme | `#faf6ef` | casa, fundo do site |
| Cipreste | `#8fb39a` | árvores |
| Piscina | `#3fb8c9` | onda |

**Fontes:** Fraunces SemiBold (nome) e Inter SemiBold (textos de apoio). São gratuitas, do Google Fonts.

## Arquivos
- `uaicasa-avatar.svg` / `avatar-1080.png`: foto de perfil (WhatsApp Business, Instagram, Facebook, Google Meu Negócio)
- `uaicasa-simbolo.svg` / `icone-1024.png`: ícone de app (cantos arredondados)
- `uaicasa-simbolo-quadrado.svg` / `icon-maskable-512.png`: ícone sem cantos (iOS e Android arredondam sozinhos)
- `uaicasa-logo-horizontal(.svg/.png)`: para fundos claros
- `uaicasa-logo-horizontal-escuro(.svg/.png)`: com fundo verde; `uaicasa-logo-horizontal-branco.svg` é a versão sem fundo, para fotos e fundos escuros
- `uaicasa-logo-vertical(.svg/.png)`: placas, cartões, adesivos
- `favicon.svg`: versão simplificada para tamanhos pequenos
- `opengraph-image.jpg`: imagem que aparece ao compartilhar o link (1200×630)

Use os arquivos SVG para impressão: eles ampliam sem perder qualidade.
